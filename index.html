DSA Behind RainVision

Concept Where it is used in RainVision Complexity
Array Stores all 4188 records, the 12 monthly values of each record, and the list of 36 subdivision names. Loops visit the items one by one. Access by index: O(1). Visiting all items: O(n).
Object Each CSV row is stored as an object with named properties such as subdivision, year and annual. Reading a property: O(1).
Aggregation (running totals) Averages, highest and lowest values, monthly, yearly and seasonal averages. One loop keeps a total and a count and skips missing values. O(n)
Linear Search Finds a subdivision by checking the names one by one, in the order of the CSV. The comparisons are counted. Best: O(1). Worst: O(n).
Binary Search Finds a subdivision in the A to Z sorted list by repeatedly halving the search area. It needs sorted data. Best: O(1). Worst: O(log n).
Insertion Sort Sorts the subdivision names A to Z (needed for Binary Search). Also used in the sorting comparison table. Worst: O(n²). Extra space: O(1).
Merge Sort Ranks the 36 subdivisions by average annual rainfall. It splits the list in halves, sorts each half and merges them. O(n log n). Extra space: O(n).

Searching, sorting and all calculations are written in JavaScript in this project. No built-in sort or search function is used for them. The free library Chart.js is used only to draw the charts.

About the Dataset

  • Name: India's Rainfall Data (file: Sub_Division_IMD_2017.csv), downloaded from Kaggle.
  • Size: 4188 records and 19 columns, for 36 meteorological subdivisions.
  • Time period: 1901 to 2017.
  • Columns: SUBDIVISION, YEAR, JAN to DEC (monthly rainfall), ANNUAL, JF (Jan-Feb), MAM (Mar-May), JJAS (Jun-Sep, the monsoon season) and OND (Oct-Dec).
  • Unit: rainfall is measured in millimetres (mm).

Limitations

  • The rows are meteorological subdivisions, not states. Some are a whole state, some are only a part of a state.
  • Some values are missing (written as NA). Missing values are skipped in the calculations and are never treated as zero. A zero in the data means no rain.
  • Not every subdivision has all 117 years. For example, Arunachal Pradesh has fewer years with an annual value.
  • The yearly trend uses 34 to 36 subdivisions per year, so it is not based on exactly the same subdivisions in every year.
  • The data ends in 2017.
  • One subdivision name is spelled "Matathwada" in the dataset. It is shown here exactly as in the file.
